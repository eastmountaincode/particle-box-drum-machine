# Vintage drum kit sources

The `cr-78`, `lm-2`, `mrk-2`, and `tr-505` directories are copied from
[`oramics/sampled`](https://github.com/oramics/sampled) at commit
`84d3405e107ad52986e7ca99af6a4ed3efe205de`.

Each source directory identifies its audio samples as Public Domain in its
bundled `README.md` and metadata files. The complete source directories are
retained here for provenance, although the drum machine currently maps only
the kick, snare, hi-hat, and tom/percussion voices from each kit.

- `cr-78`: Roland CompuRhythm CR-78
- `lm-2`: LinnDrum LM-2
- `mrk-2`: Maestro Rhythm King MRK-2
- `tr-505`: Roland TR-505

Source tree:
